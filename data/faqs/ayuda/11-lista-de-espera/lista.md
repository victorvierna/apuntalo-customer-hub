# Lista de espera

La lista de espera recoge solicitudes de clientes que quieren un hueco. Un aviso no reserva la hora: la cita debe completarse antes de que otro cliente la ocupe.

## Añadir y gestionar una solicitud

1. En **Citas**, inicia la creación de una cita y pulsa **Añadir a lista de espera**.
2. Elige cliente y servicio, profesional o **Cualquier profesional**, fechas y disponibilidad. Puedes añadir una nota interna.
3. Pulsa **Añadir**. En la agenda, abre el indicador de **Lista de espera** del día para consultar las solicitudes y usar **Editar**, **Reservar**, **Ver cliente** o **Quitar**. En la ficha del cliente también puedes consultar sus solicitudes y usar **Ver en agenda**.
4. Si eliges **Reservar**, revisa el hueco propuesto y completa la cita. Si ya no está libre, selecciona otro.

Si el cliente ya tiene una solicitud igual, revisa la existente antes de añadir otra. Si falla el guardado, revisa la conexión y vuelve a abrir la lista para comprobar si se aplicó.

## Ofertas para el cliente

Desde la página de reserva, el cliente puede pulsar **Avisarme si se libera un hueco**, elegir días, horario y profesional y confirmar con **Avisarme**. Puede editarla o usar **Salir de la lista** desde **Mi lista de espera**. Al recibir un aviso, debe abrirlo y completar la reserva. Si el aviso ha caducado, el hueco ya está ocupado o corresponde a otra cuenta, puede buscar otro horario o entrar con la cuenta correcta. Consulta la [guía del cliente](../17-guia-del-cliente/reservar.md).

## Preguntas frecuentes y opciones que no aparecen

### ¿Apuntarme a la lista garantiza la próxima hora libre?
No. La solicitud permite recibir una oferta, pero no ocupa una hora. El cliente debe completar la reserva mientras el hueco siga disponible.

### ¿Por qué no puedo pulsar «Añadir»?
La solicitud necesita una elección válida de servicio, agenda y disponibilidad. Completa los campos indicados y espera si ya se está guardando.

### ¿Puedo añadir una solicitud desde la ficha del cliente?
La ficha permite consultar sus solicitudes y abrirlas en la agenda. Para crear otra, inicia **Nueva cita** y usa **Añadir a lista de espera**.
