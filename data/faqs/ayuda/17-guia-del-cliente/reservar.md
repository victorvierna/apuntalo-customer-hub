# Reservar y gestionar tus citas

Esta guía es para clientes de un negocio. Necesitas el enlace de reservas del centro y un teléfono al que puedas recibir un código.

## Entrar y reservar

1. Abre el enlace que te ha dado el negocio. Busca en **Servicios** y selecciona el que necesitas. Puedes añadir otro servicio si aparece la opción.
2. Elige profesional o **Cualquiera**, día y hora disponibles. Si no aparecen huecos, prueba otra fecha o profesional. Para varios servicios, puede que no haya tiempo para todos seguidos.
3. Cuando se solicite, introduce **Tu móvil**, elige recibir el código por WhatsApp o SMS y escribe el código recibido. Si es tu primera vez, completa tu nombre y pulsa **Registrarse**.
4. Revisa los datos y cualquier condición o importe mostrado. Completa la reserva y espera la confirmación **Cita creada**. Pulsa **Ver mis reservas** para comprobarla.

Si no llega el código, revisa el número y prueba la alternativa de SMS si aparece. Si abriste el enlace dentro de Instagram y falla el acceso, ábrelo en Safari o Chrome. Espera el tiempo indicado si has hecho demasiados intentos.

## Consultar, cambiar o cancelar

En **Próximas citas**, abre la cita para ver sus servicios, hora y datos del negocio. **Historial** muestra citas antiguas; **Ver negocios recientes** ayuda a volver a un centro. Usa **Cambiar fecha** o **Cancelar cita** si aparecen y sigue las indicaciones. Algunas citas o cambios requieren contactar con el negocio.

Lee los avisos antes de cancelar: si terminó el plazo de cancelación gratuita, un importe ya cobrado no se devuelve automáticamente y el negocio puede tener que decidir sobre una garantía. Si respondes **No podré asistir** a una solicitud de confirmación, avisas al centro pero no cancelas la reserva. Para cancelarla, usa la acción de cancelación disponible.

Si el hueco se ocupa mientras reservas, elige otro. Si no ves una cita, comprueba que entraste con el mismo teléfono y consulta **Próximas citas**; si sigue sin aparecer, contacta con el negocio antes de reservar de nuevo.

## Lista de espera, bonos y pago

Cuando aparezca **Avisarme si se libera un hueco**, elige tus preferencias y pulsa **Avisarme**. El aviso no reserva la hora: abre la oferta y completa la reserva. Si ya no está disponible, busca otra hora. Puedes revisar o abandonar solicitudes en **Mi lista de espera**.

En **Mis bonos** puedes abrir **Detalles** para consultar sesiones disponibles, vigencia, sesiones utilizadas y sesiones en una reserva pendiente. Desde el bono puedes pulsar **Reservar** o **Ver negocio**. Cuando aparezca la opción, usa **Añadir a Apple Wallet** o **Añadir a Google Wallet** para llevarlo en la cartera del dispositivo. Si no se abre, inténtalo de nuevo. Revisa si la cita queda cubierta o tiene un importe adicional. Si la reserva pide pago, revisa el importe y termina el proceso; comprueba la confirmación y el estado de la cita. Ante dudas sobre cargos o devoluciones, contacta con el negocio.

## Perfil y avisos

En **Mi perfil** puedes cambiar nombre, idioma y modo oscuro, conectar Google Calendar o cerrar sesión. En los detalles de una cita también puedes abrir **Mensajes** o **Escribir al negocio** y enviar texto o una foto cuando la conversación esté disponible. Para eliminar la cuenta, usa **Eliminar perfil** y confirma: tus citas actuales no se cancelan automáticamente, por lo que debes gestionarlas con cada negocio. Activa los recordatorios y permite las notificaciones en tu dispositivo si quieres recibir avisos. Para instalar la aplicación, usa la opción de instalación que aparezca en tu dispositivo.

## Preguntas frecuentes y opciones que no aparecen

### ¿Por qué no aparece «Cambiar fecha»?
La opción depende del plazo permitido y de que el negocio permita el cambio. Las reservas con varios servicios o un combo se cambian a través del negocio. Usa sus datos de contacto para pedir el cambio; no canceles para probar sin revisar antes las condiciones.

### ¿Por qué no aparece «Activar recordatorios»?
El dispositivo debe admitir notificaciones. Además, si ya has dado permiso, no se vuelve a ofrecer el mismo botón. Revisa los permisos del sistema o navegador si los avisos no llegan.

### ¿Eliminar mi perfil cancela todas mis reservas?
No. Gestiona tus citas con cada negocio antes de eliminar el perfil. La eliminación de tu acceso no sustituye una cancelación ni una decisión sobre cargos.

### ¿La lista de espera y el bono garantizan una hora?
No. La lista permite recibir un aviso y el bono puede cubrir sesiones, pero la cita necesita un hueco disponible y completar la reserva.
